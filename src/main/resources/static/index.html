About TypeFlow

Every keystroke counts.

TypeFlow is a full-stack typing speed test and performance analytics platform engineered with a high-performance Java Spring Boot backend, Spring Security, MySQL / file-backed persistence, and a modern responsive vanilla frontend.

Formulas & Scoring Engine

  • • Word Definition: Standard international convention of 5 characters = 1 word.
  • • Raw WPM: (Total characters typed / 5) ÷ Elapsed minutes.
  • • Net WPM: (Correct characters / 5) ÷ Elapsed minutes.
  • • Accuracy: (Correct characters / Total typed characters) × 100%.
  • • 24-Hour Leaderboard: Strictly enforces a rolling 24-hour qualifying window on the server side.

Technology Architecture

Backend: Java 17+, Spring Boot 3.3.4
Security: Spring Security, BCrypt
Database: MySQL 8.0+ / H2 Engine
Visuals: Vanilla CSS, Chart.js, Web Audio API
